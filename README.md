# Jarvis Dashboard

A web dashboard for monitoring and controlling the Jarvis MT5 automated trading platform.

---

## Features

- Live EA Status
- Start Trading
- Stop Trading
- Trading Enabled Indicator
- Account Balance
- Equity
- Open Positions
- Current Symbol
- Last Updated Timestamp

---

## Technology Stack

- React
- Next.js
- TypeScript
- AWS API Gateway
- AWS Lambda
